# Study執筆ガイド

この文書は教材本文ではなく、Studyを追加・修正するときの執筆者向けガイドです。

## 用語と表記

- 正確な定訳があり、日本語の文献でも日本語表記の方が一般的な用語は日本語にします。例：情報集合、
  終端ノード、純粋戦略、混合戦略、行動戦略、最適反応、ゼロ和、定和、利得。
- 直訳が不自然な用語や、ポーカー・ソルバーの解説で英語の方が一般的な用語は英語のまま使います。
  例：off-path、reach、counterfactual regret、Exploitability、Node lock、range advantage。
- EV、EQ、EQR、MDF、SPR、CFRは、基礎文書の初出で正式名称を示し、以後は略語に統一します。
- `Fold equity`、`Equity denial`のように一まとまりで定着した複合用語は、単独のEQと区別して名称を保持します。
- Check、Bet、Call、Raise、Fold、All-inは、ゲームとStrategy Viewerのaction名に合わせます。
- range、hand、pot、stack、street、showdownなど、この教材とソルバーで定着している語は英語で統一します。
- UI label、設定key、ファイル名、数式中の変数名は実装どおりの表記を保持します。

## handとrank

プレイヤーに配られるものはhandです。rankはhandの強さを表す値として使います。

- AKQ型ゲーム：A、K、Qをhandと呼び、`A > K > Q`を勝敗判定として示します。
- 数値型ゲーム：`rank rのhand`、`rankが高いhand`のように書きます。
- 戦略表：handを行に並べる場合は`OOP hand`、数値を帯域でまとめる場合は`rank帯`とします。
- Strategy Viewer：実装上のhand識別子が`rank`である場合は、UI labelとしてそのまま記載できます。

## ルール表と構成

ルール表はstandard minimum raiseを既定とします。「アクション制約」には、Node lock、強制Check、Raise不可、
standard minimum raiseを使わない場合など、既定から外れる条件だけを記載します。

理論上Bet sizeを自由に選べるStudyでは、「許可アクション」に任意サイズと記載します。Solverへ与える
10/20/33%などの有限候補はルールに混ぜず、「Solverによる再現」でaction abstractionとして明記します。
固定All-inや固定Pot Betのゲームだけは、固定sizeをルールとして記載します。

新しいStudyは[`zz_template.md`](zz_template.md)を使い、教材の通読順に追加する場合だけ`study_XX_...md`の
連番を付けます。

「導出方法」の先頭では、局面、手番、handまたはrank帯、比較するaction、結論を表で整理します。その後、
表と同じ順序で場合分けし、純粋actionの理由、混合戦略の無差別条件、EVの順に説明します。

閉形式の均衡を主張する場合は、使用actionの無差別条件だけでなく、未使用actionへの逸脱不等式、自由なBet sizeの
大域的最適性、Raiseとoff-path応答を確認します。support仮定付きの候補や有限actionの数値解は、連続ゲームの
均衡と区別して記載します。

## 前提・解析・数値結果の区別

均衡の説明は、次の三つを混ぜません。

1. **ルールまたは解析上の前提**：All-inだけを許す、Pot Betに固定する、数値解で観察したsupportを固定する。
2. **数学的に導出した結論**：無差別条件から決まる比率や頻度、逸脱不等式まで確認したsize、EV。
3. **Solverによる数値結果**：有限action abstractionで得たsupport、頻度、Exploitability。

あるBet sizeがminimum raiseの境界に一致する、後続の無差別条件と整合する、Solverで高頻度になる、という事実だけで、
そのsizeが連続actionゲームの最適解だとは証明しません。必要条件と十分条件を示せない場合はsizeを明示的な前提または
数値結果として扱い、その前提から厳密に導ける内容だけを「導出」と呼びます。

混合戦略では、比率と絶対頻度を分けます。無差別条件からBet rangeの構成比だけが決まり、共通倍率が残る場合は、
「比率を保った頻度変更」が未解決であることを明記します。絶対頻度の特定に相手のcontinuation strategyや将来streetの
戦略が必要なら、補足ではなく導出の本体として、その依存関係が分かる順序で説明します。

## 初見の読者を基準にする

教材本文は、過去の版やレビュー時の議論を知らない読者だけを想定して書きます。

- 「以前は」「後付けではなく」「つじつまを合わせるためではなく」のような、修正経緯への応答を本文へ残しません。
- 数値解を解析の出発点にする場合は、「Solverでsize $`x`$が得られたため、本Studyでは $`x`$を固定して頻度を
  導出する」と、何を与え、何を学ぶかを先に示します。
- 省略する証明は、難しさを弁明せず、「全sizeと応答を扱う証明は省略する」のように対象だけを簡潔に示します。
- 同じ注意書きを、導入・導出・備考で繰り返しません。読者が結果の意味を誤解し得る最初の箇所で一度説明します。
- 「証明できなかったこと」から節を始めず、そのStudyが実際に扱うゲーム、解法、学べる結論から説明します。
- 既出のStudyを参照する場合は、参照先を読まなくても現在の段落の要点を理解できる文章にします。
